Solution examples

Old Pochmann algorithms for each sticker target, in tracing order.

Each example shows setup moves, a named permutation, and the undo moves. Expand it to see the full algorithm.

These examples cover traced targets. Parity handling, flipped edges, and in-place corner twists need separate algorithms.
